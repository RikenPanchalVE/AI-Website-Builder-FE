# AI Website Builder — Client

React + Vite frontend.

## Setup

```bash
npm install
npm run dev
```

## Stack

- React 19
- Vite
- Tailwind CSS v4
- Shadcn UI
- Redux Toolkit
- React Router
- Axios
- React Hook Form + Zod

## Ports

| Service | Port |
|---------|------|
| Dev Server | 5173 |
| API Proxy | 5000 (via Vite proxy) |
